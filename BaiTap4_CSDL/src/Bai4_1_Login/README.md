Mở [BaiTap4_CSDL.sln](../../BaiTap4_CSDL.sln), chọn **Bai4_1_Login** làm Startup Project rồi nhấn F5.

- Kiểm tra thông tin trống bằng ErrorProvider.
- Checkbox hiện/ẩn mật khẩu; Enter đăng nhập, Esc thoát.
- Tài khoản đọc từ bảng AppUsers; lưu kết quả vào LoginAttempts.
- Tài khoản mẫu: `admin` / `Admin@123`.

Mã xử lý: [FrmLogin.cs](FrmLogin.cs). Giao diện: [FrmLogin.Designer.cs](FrmLogin.Designer.cs).
